## ما هو Lumen؟

مشغّل Lumen هو مشغّل وسائط تفتحه في تبويب من تبويبات المتصفح. تخيّل مشغّلًا لسطح المكتب مثل mpv أو VLC أُعيد بناؤه بتقنيات الويب الحديثة. ملفاتك لا تغادر حاسوبك أبدًا: كل شيء يُفكّ ترميزه ويُعرض محليًا داخل الصفحة نفسها.

ما الذي يستطيع فعله:

- **تشغيل كل شيء تقريبًا.** ملفات MP4 و MKV و WebM و MPEG-TS و AVI و FLV، وفيديو H.264 و HEVC و VP9 و AV1 والصيغ الأقدم، وصوت AAC و Opus و MP3 و AC-3 و FLAC. وعندما لا يستطيع المتصفح فك ترميز ملف بنفسه، ينتقل Lumen إلى نسخة مدمجة من FFmpeg.
- **البقاء سلسًا ومتزامنًا.** يُفكّ ترميز الفيديو عبر عتاد الرسوميات كلما أمكن، ويُرسم بواسطة معالج الرسوميات (GPU)، وتبقى الصورة متزامنة مع الصوت بفارق لا يتجاوز بضعة أجزاء من الألف من الثانية.
- **عرض الترجمة كما يجب.** ترجمات ASS/SSA المنسّقة (المستخدمة في الأنمي والكاريوكي)، و SRT و WebVTT و PGS الخاصة بأقراص Blu-ray، بما فيها مسارات الترجمة والخطوط المضمّنة داخل ملفات MKV.
- **تغيير مظهره.** يأتي مع ثلاثة مظاهر، ويمكنك صنع مظهرك الخاص بملف JSON صغير.
- **التحكم به من لوحة المفاتيح.** الاختصارات نفسها المستخدمة في mpv: التنقل إطارًا بإطار، والتحكم بالسرعة، وتأخير الترجمة، والتكرار بين نقطتين A-B وغير ذلك.
- **إظهار ما يجري في الداخل.** اضغط `i` لفتح لوحة إحصاءات حيّة.

## قبل أن تبدأ

تحتاج إلى تثبيت ثلاثة أشياء:

1. **الإصدار 22 أو أحدث من Node.js** (الإصدار 20.19 وما بعده يعمل أيضًا): نزّله من [nodejs.org](https://nodejs.org). للتحقق، افتح الطرفية ونفّذ الأمر `node --version`.
2. **برنامج Git**: نزّله من [git-scm.com](https://git-scm.com).
3. **متصفح Microsoft Edge أو Google Chrome** بإصدار حديث. يعتمد Lumen على ميزات جديدة في المتصفحات (WebCodecs و WebGPU)، وهذان هما المتصفحان اللذان يُختبر عليهما.

تحتاج أيضًا إلى نحو 500 ميغابايت من المساحة الحرة على القرص للاعتماديات وملفات الفيديو التجريبية.

## البدء

افتح الطرفية (في ويندوز: PowerShell أو Windows Terminal) ونفّذ هذه الأوامر واحدًا تلو الآخر.

**1. نزّل الشيفرة**

```bash
git clone https://github.com/manb0fish/lumen-web-player.git
```

```bash
cd lumen-web-player
```

**2. ثبّت الاعتماديات** (يستغرق ذلك دقيقة أو دقيقتين)

```bash
npm install
```

**3. أنشئ ملفات الفيديو التجريبية** (خطوة اختيارية، لكنها تمنحك شيئًا تشغّله فورًا)

```bash
npm run media
```

ينشئ هذا الأمر نحو 30 مقطعًا تجريبيًا قصيرًا على حاسوبك. لا يُنزَّل أي شيء من الإنترنت.

**4. ابدأ تشغيل المشغّل**

```bash
npm run dev
```

الآن افتح **<http://127.0.0.1:5173>** في Edge أو Chrome. سترى المشغّل ومعه قائمة بالمقاطع التجريبية على اليسار. انقر على أي مقطع لتشغيله.

لإيقاف المشغّل، عُد إلى الطرفية واضغط `Ctrl+C`.

## استخدام المشغّل

- **تشغيل ملف من عندك:** اسحبه إلى المشغّل، أو انقر على أيقونة المجلد.
- **إضافة ترجمة:** اسحب إلى المشغّل ملفًا بأحد الامتدادات <span dir="ltr">`.ass`</span> أو <span dir="ltr">`.srt`</span> أو <span dir="ltr">`.vtt`</span> أو <span dir="ltr">`.sup`</span>. الترجمات الموجودة داخل ملفات MKV تُكتشف تلقائيًا؛ اختر واحدة من قائمة الترجمة.
- **تغيير المظهر:** انقر على أيقونة لوحة الألوان، أو اضغط `K`.
- **تغيير خيارات جودة الصورة:** أيقونة المنزلقات تفتح إعدادات العارض والتكبير والمرشّحات.
- **عرض التفاصيل التقنية:** اضغط `i`.

## مشكلات شائعة

**الأمر `npm run media` يقول إن ffmpeg غير موجود.**
تعذّر على حزمة ffmpeg المساعدة تشغيل برنامج التثبيت الخاص بها. نفّذ هذين الأمرين ثم حاول مجددًا:

```bash
npm install-scripts approve ffmpeg-static
```

```bash
npm rebuild ffmpeg-static
```

إذا ظهر أن الأمر الأول غير معروف، فإصدار npm لديك أقدم ولا يحتاج إليه: نفّذ الأمر الثاني فقط.

**قائمة المقاطع التجريبية فارغة.**
نفّذ الأمر `npm run media` ثم أعد تحميل الصفحة.

**الصفحة لا تُحمَّل.**
تأكد من أن الأمر `npm run dev` ما زال يعمل في الطرفية، وأن العنوان هو `http://127.0.0.1:5173` بالضبط.

**تظهر الرسالة "Audio is blocked by the browser".**
المتصفحات لا تسمح للصفحات بأن تبدأ تشغيل الصوت من تلقاء نفسها. انقر مرة واحدة على المشغّل ثم اضغط زر التشغيل.

**المشغّل لا يعمل في Firefox أو Safari.**
استخدم Microsoft Edge أو Google Chrome حاليًا، فهما المتصفحان اللذان يُطوَّر Lumen ويُختبر عليهما.

**ملف لا يعمل.**
اضغط `i` لمعرفة مفكّك الترميز الذي اختير ولماذا. هناك قيد معروف: نسخة FFmpeg المدمجة لا تستطيع فك ترميز فيديو AV1، لذا تحتاج إلى متصفح يدعم AV1 بنفسه (الإصدارات الحالية من Edge و Chrome تدعمه).

## للمطوّرين

يمكن استخدام Lumen كمكتبة أيضًا: نواة مشغّل بلا واجهة، وفوقها واجهة مستخدم اختيارية.

```ts
import { Player, mountUI } from './src';

const player = new Player({ container });
mountUI(player, container, { skin: 'glass' });
await player.load(fileOrUrl, { autoplay: true });
player.command('seek 30 absolute');
```

شغّل الفحوصات:

```bash
npm run lint
```

```bash
npm test
```
