## Lumen क्या है?

Lumen एक मीडिया प्लेयर है जिसे आप ब्राउज़र के टैब में खोलते हैं। इसे mpv या VLC जैसा डेस्कटॉप
प्लेयर समझिए, जिसे आधुनिक वेब तकनीक से दोबारा बनाया गया है। आपकी फ़ाइलें कभी आपके कंप्यूटर से
बाहर नहीं जातीं: सब कुछ उसी पेज के अंदर, आपके कंप्यूटर पर ही डिकोड होकर दिखाया जाता है।

यह क्या-क्या कर सकता है:

- **लगभग हर चीज़ चलाता है।** MP4, MKV, WebM, MPEG-TS, AVI और FLV फ़ाइलें; H.264, HEVC, VP9, AV1
  और पुराने वीडियो फ़ॉर्मैट; AAC, Opus, MP3, AC-3 और FLAC ऑडियो। जब ब्राउज़र किसी फ़ाइल को खुद
  डिकोड नहीं कर पाता, तो Lumen अपने अंदर मौजूद FFmpeg का इस्तेमाल करता है।
- **स्मूद और सिंक में रहता है।** जहाँ तक हो सके, वीडियो आपके ग्राफ़िक्स हार्डवेयर से डिकोड होता
  है और GPU से ड्रॉ होता है, और तस्वीर आवाज़ के साथ कुछ मिलीसेकंड के भीतर तालमेल में रहती है।
- **सबटाइटल ठीक से दिखाता है।** स्टाइल वाले ASS/SSA सबटाइटल (जो ऐनिमे और कराओके में इस्तेमाल होते
  हैं), SRT, WebVTT और ब्लू-रे PGS, साथ ही MKV फ़ाइलों के अंदर रखे सबटाइटल ट्रैक और फ़ॉन्ट भी।
- **अपना रूप बदलता है।** तीन स्किन साथ आती हैं, और एक छोटी-सी JSON फ़ाइल से आप अपनी स्किन बना
  सकते हैं।
- **कीबोर्ड से चलता है।** वही शॉर्टकट जो mpv में हैं: फ़्रेम-दर-फ़्रेम चलाना, स्पीड कंट्रोल,
  सबटाइटल डिले, A-B लूप वगैरह।
- **फ़ोन और टैबलेट पर चलता है।** छोटी स्क्रीन पर कंट्रोल अपने-आप नए सिरे से सजते हैं और टच से चलते
  हैं: 10 सेकंड आगे या पीछे जाने के लिए तस्वीर के दाईं या बाईं ओर दो बार टैप करें।
- **अंदर क्या चल रहा है, यह दिखाता है।** लाइव आँकड़ों का पैनल खोलने के लिए `i` दबाएँ।

## शुरू करने से पहले

आपके कंप्यूटर पर तीन चीज़ें इंस्टॉल होनी चाहिए:

1. **Node.js 22 या उससे नया** (20.19 या उससे नया भी चलेगा): [nodejs.org](https://nodejs.org) से
   डाउनलोड करें। जाँचने के लिए टर्मिनल खोलें और `node --version` चलाएँ।
2. **Git**: [git-scm.com](https://git-scm.com) से डाउनलोड करें।
3. **Microsoft Edge या Google Chrome का नया संस्करण।** Lumen ब्राउज़र की नई सुविधाओं (WebCodecs,
   WebGPU) पर निर्भर है, और इसकी जाँच इन्हीं दो ब्राउज़रों पर की जाती है।

डिपेंडेंसी और सैंपल वीडियो के लिए लगभग 500 MB खाली डिस्क स्पेस भी चाहिए।

## शुरुआत करें

टर्मिनल खोलें (Windows पर: PowerShell या Windows Terminal) और ये कमांड एक-एक करके चलाएँ।

**1. कोड डाउनलोड करें**

```bash
git clone https://github.com/manb0fish/lumen-web-player.git
```

```bash
cd lumen-web-player
```

**2. डिपेंडेंसी इंस्टॉल करें** (एक-दो मिनट लगते हैं)

```bash
npm install
```

**3. सैंपल वीडियो बनाएँ** (वैकल्पिक है, पर इससे तुरंत चलाने के लिए कुछ मिल जाता है)

```bash
npm run media
```

इससे आपके कंप्यूटर पर करीब 30 छोटी टेस्ट क्लिप बनती हैं। कुछ भी डाउनलोड नहीं होता।

**4. प्लेयर शुरू करें**

```bash
npm run dev
```

अब Edge या Chrome में **<http://127.0.0.1:5173>** खोलें। आपको प्लेयर दिखेगा, और बाईं ओर सैंपल
क्लिप की सूची होगी। किसी भी क्लिप पर क्लिक करके उसे चलाएँ।

प्लेयर बंद करने के लिए टर्मिनल पर लौटें और `Ctrl+C` दबाएँ।

## प्लेयर का इस्तेमाल

- **अपनी फ़ाइल चलाएँ:** उसे प्लेयर पर खींचकर छोड़ें, या फ़ोल्डर आइकन पर क्लिक करें।
- **सबटाइटल जोड़ें:** `.ass`, `.srt`, `.vtt` या `.sup` फ़ाइल को प्लेयर पर खींचकर छोड़ें। MKV
  फ़ाइलों के अंदर के सबटाइटल अपने-आप मिल जाते हैं; सबटाइटल मेन्यू से कोई एक चुनें।
- **स्किन बदलें:** पैलेट आइकन पर क्लिक करें, या `K` दबाएँ।
- **पिक्चर क्वालिटी के विकल्प बदलें:** स्लाइडर वाला आइकन रेंडरर, स्केलर और फ़िल्टर की सेटिंग
  खोलता है।
- **तकनीकी जानकारी देखें:** `i` दबाएँ।

## आम समस्याएँ

**`npm run media` कहता है कि ffmpeg नहीं मिला।**
ffmpeg का सहायक पैकेज अपना इंस्टॉलर नहीं चला पाया। ये दो कमांड चलाएँ और फिर कोशिश करें:

```bash
npm install-scripts approve ffmpeg-static
```

```bash
npm rebuild ffmpeg-static
```

अगर पहला कमांड "unknown command" बताए, तो आपका npm पुराना संस्करण है जिसे इसकी ज़रूरत नहीं:
सिर्फ़ दूसरा कमांड चलाएँ।

**सैंपल सूची खाली है।**
`npm run media` चलाएँ, फिर पेज रीलोड करें।

**पेज लोड नहीं होता।**
देख लें कि टर्मिनल में `npm run dev` अब भी चल रहा है, और पता ठीक `http://127.0.0.1:5173` ही है।

**"Audio is blocked by the browser" लिखा आता है।**
ब्राउज़र किसी पेज को अपने-आप आवाज़ चलाने नहीं देते। प्लेयर पर एक बार क्लिक करें, फिर प्ले दबाएँ।

**Firefox या Safari में नहीं चलता।**
फ़िलहाल Microsoft Edge या Google Chrome का इस्तेमाल करें। Lumen इन्हीं ब्राउज़रों पर बनाया और
परखा जाता है।

**कोई फ़ाइल नहीं चलती।**
`i` दबाकर देखें कि कौन-सा डिकोडर चुना गया और क्यों। एक ज्ञात सीमा: अंदर मौजूद FFmpeg AV1 वीडियो
डिकोड नहीं कर सकता, इसलिए AV1 के लिए ऐसा ब्राउज़र चाहिए जो उसे खुद सपोर्ट करता हो (Edge और
Chrome के मौजूदा संस्करण करते हैं)।

## डेवलपर के लिए

Lumen एक लाइब्रेरी भी है: बिना इंटरफ़ेस वाला प्लेयर कोर, और उसके ऊपर एक वैकल्पिक यूज़र
इंटरफ़ेस।

```ts
import { Player, mountUI } from './src';

const player = new Player({ container });
mountUI(player, container, { skin: 'glass' });
await player.load(fileOrUrl, { autoplay: true });
player.command('seek 30 absolute');
```

जाँच चलाएँ:

```bash
npm run lint
```

```bash
npm test
```

और जानकारी (अंग्रेज़ी में):

- [गाइड](../GUIDE.md): URL विकल्प, सभी शॉर्टकट, अपने पेज में जोड़ना, स्किन बनाना और टेस्ट सूट।
- [आर्किटेक्चर](../ARCHITECTURE.md): डिकोडिंग, रेंडरिंग, ऑडियो सिंक और सबटाइटल कैसे काम करते हैं,
  और उनके पीछे के डिज़ाइन समझौते।
- [सत्यापन](../VERIFICATION.md): 202 ऑटोमेटेड टेस्ट क्या नापते हैं, और उनके नतीजे।
