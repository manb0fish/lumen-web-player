## Что такое Lumen?

Lumen — это медиаплеер, который открывается во вкладке браузера. Представьте настольный плеер
вроде mpv или VLC, заново собранный на современных веб-технологиях. Ваши файлы никуда не
отправляются: всё декодируется и показывается локально, прямо на странице.

Что он умеет:

- **Воспроизводит почти всё.** Файлы MP4, MKV, WebM, MPEG-TS, AVI и FLV; видео H.264, HEVC, VP9,
  AV1 и более старые форматы; звук AAC, Opus, MP3, AC-3 и FLAC. Если браузер не может
  декодировать файл сам, Lumen переключается на встроенную копию FFmpeg.
- **Работает плавно и без рассинхронизации.** Когда это возможно, видео декодируется аппаратно и
  отрисовывается на GPU, а изображение совпадает со звуком с точностью до нескольких
  миллисекунд.
- **Правильно показывает субтитры.** Стилизованные субтитры ASS/SSA (те, что используются в
  аниме и караоке), SRT, WebVTT и PGS с Blu-ray, включая дорожки субтитров и шрифты, вложенные в
  файлы MKV.
- **Меняет внешний вид.** В комплекте три темы оформления, а свою можно сделать с помощью
  небольшого JSON-файла.
- **Управляется с клавиатуры.** Те же сочетания клавиш, что и в mpv: покадровый переход,
  скорость воспроизведения, задержка субтитров, повтор отрезка A-B и многое другое.
- **Работает на телефонах и планшетах.** Элементы управления сами перестраиваются под небольшой
  экран и реагируют на касания: двойное касание слева или справа от центра перематывает на
  10 секунд.
- **Показывает, что происходит внутри.** Нажмите `i`, чтобы открыть панель статистики в реальном
  времени.

## Что понадобится

Нужно установить три вещи:

1. **Node.js 22 или новее** (подойдёт и 20.19 или новее): скачайте с
   [nodejs.org](https://nodejs.org). Чтобы проверить версию, откройте терминал и выполните
   `node --version`.
2. **Git**: скачайте с [git-scm.com](https://git-scm.com).
3. **Свежая версия Microsoft Edge или Google Chrome.** Lumen использует новые возможности
   браузеров (WebCodecs, WebGPU), и тестируется он именно в этих двух браузерах.

Ещё потребуется около 500 МБ свободного места на диске для зависимостей и демонстрационных
видео.

## Быстрый старт

Откройте терминал (в Windows — PowerShell или Windows Terminal) и выполните команды по одной.

**1. Скачайте код**

```bash
git clone https://github.com/manb0fish/lumen-web-player.git
```

```bash
cd lumen-web-player
```

**2. Установите зависимости** (займёт минуту-две)

```bash
npm install
```

**3. Создайте демонстрационные видео** (необязательно, но так будет что включить сразу)

```bash
npm run media
```

Команда создаст на вашем компьютере около 30 коротких тестовых роликов. Ничего не скачивается.

**4. Запустите плеер**

```bash
npm run dev
```

Теперь откройте **<http://127.0.0.1:5173>** в Edge или Chrome. Вы увидите плеер, а слева —
список демонстрационных роликов. Щёлкните по любому, чтобы его воспроизвести.

Чтобы остановить плеер, вернитесь в терминал и нажмите `Ctrl+C`.

## Как пользоваться плеером

- **Открыть свой файл:** перетащите его на плеер или нажмите на значок папки.
- **Добавить субтитры:** перетащите на плеер файл `.ass`, `.srt`, `.vtt` или `.sup`. Субтитры
  внутри файлов MKV находятся автоматически — выберите нужные в меню субтитров.
- **Сменить тему:** нажмите на значок палитры или клавишу `K`.
- **Изменить настройки качества изображения:** значок с ползунками открывает параметры
  рендерера, масштабирования и фильтров.
- **Посмотреть технические подробности:** нажмите `i`.

### Полезные сочетания клавиш

| Клавиша | Действие |
| --- | --- |
| `Space` | Воспроизведение / пауза |
| `←` `→` | Назад / вперёд на 5 секунд |
| `,` `.` | Назад / вперёд на один кадр |
| `[` `]` | Медленнее / быстрее |
| `9` `0` | Тише / громче |
| `m` | Выключить звук |
| `z` `x` | Показывать субтитры раньше / позже |
| `v` | Показать / скрыть субтитры |
| `l` | Повтор между двумя точками (нажмите в точке A, затем в точке B; ещё одно нажатие отменяет повтор) |
| `f` | Полноэкранный режим |
| `K` | Следующая тема |
| `i` | Статистика |

Полный список и способ переназначить клавиши — в [руководстве](../GUIDE.md#keyboard-shortcuts)
(на английском).

## Частые проблемы

**`npm run media` сообщает, что ffmpeg не найден.**
Вспомогательный пакет ffmpeg не смог запустить свой установочный скрипт. Выполните эти две
команды и попробуйте снова:

```bash
npm install-scripts approve ffmpeg-static
```

```bash
npm rebuild ffmpeg-static
```

Если первая команда сообщает, что такой команды нет, значит, у вас более старая версия npm,
которой этот шаг не нужен: выполните только вторую.

**Список примеров пуст.**
Выполните `npm run media` и обновите страницу.

**Страница не загружается.**
Убедитесь, что `npm run dev` всё ещё работает в терминале, а адрес в точности
`http://127.0.0.1:5173`.

**Появляется сообщение «Audio is blocked by the browser».**
Браузеры не разрешают страницам самостоятельно включать звук. Щёлкните по плееру один раз и
нажмите воспроизведение.

**Не работает в Firefox или Safari.**
Пока используйте Microsoft Edge или Google Chrome — именно в них Lumen разрабатывается и
тестируется.

**Файл не воспроизводится.**
Нажмите `i`, чтобы увидеть, какой декодер был выбран и почему. Известное ограничение: встроенный
FFmpeg не умеет декодировать видео AV1, поэтому нужен браузер, который поддерживает AV1 сам
(актуальные версии Edge и Chrome поддерживают).

## Для разработчиков

Lumen — это ещё и библиотека: ядро плеера без интерфейса и необязательный пользовательский
интерфейс поверх него.

```ts
import { Player, mountUI } from './src';

const player = new Player({ container });
mountUI(player, container, { skin: 'glass' });
await player.load(fileOrUrl, { autoplay: true });
player.command('seek 30 absolute');
```

Запуск проверок:

```bash
npm run lint
```

```bash
npm test
```

Подробнее (на английском):

- [Руководство](../GUIDE.md): параметры URL, все сочетания клавиш, встраивание в страницу,
  создание тем и набор тестов.
- [Архитектура](../ARCHITECTURE.md): как устроены декодирование, отрисовка, синхронизация звука
  и субтитры и какие компромиссы за этим стоят.
- [Проверка](../VERIFICATION.md): что измеряют 186 автоматических тестов и какие получены
  результаты.
